# 荖葉管理系統：Google Sheets 資料層設定

這個資料夾提供 `Code.gs`。它是荖葉管理網頁的 Google Apps Script Web App 後端，會把資料保存到你的 Google 試算表。試算表不需要公開，但 Web App 的 `/exec` 網址必須能被前端讀取。

## 1. 建立專用試算表

建立一份新的 Google 試算表，從網址中取出試算表 ID：

```text
https://docs.google.com/spreadsheets/d/這一段就是試算表ID/edit
```

不要把試算表 ID 貼到公開程式碼或傳給其他人。

## 2. 貼上程式並初始化

1. 在試算表選擇「擴充功能 → Apps Script」。
2. 打開 `Code.gs`，刪除原有內容，貼上本資料夾的 `Code.gs`。
3. 在 `CONFIG.SPREADSHEET_ID` 填入自己的試算表 ID；時區維持 `Asia/Taipei`。
4. 儲存專案。
5. 在上方函式下拉選單選擇 `setup`，按「執行」。
6. 第一次執行時完成 Google 授權。若出現未驗證畫面，選「進階」後進入目前的 Apps Script 專案。

`setup()` 會建立四個工作表：`出產紀錄`、`出貨紀錄`、`中間商`、`設定`。如果工作表已有資料但標題不符合，程式會停止，不會覆蓋既有資料。

## 3. 部署 Web App

在 Apps Script 選擇「部署 → 新增部署」：

- 類型：網頁應用程式
- 執行身分：**我**
- 誰可以存取：**任何人**
- 複製正式網址，必須以 `/exec` 結尾

不要把 `/dev` 當作正式網址；`/dev` 只適合有編輯權限的測試。更新程式後建立新版本並更新既有部署，不需要建立觸發器。

## 4. 在管理系統連線

開啟荖葉管理系統的「設定 → Google Sheets 連線」，貼入完整的：

```text
https://script.google.com/macros/s/你的部署ID/exec
```

按「測試連線並載入資料」。成功讀到資料後，再新增一筆測試出產或出貨，回到試算表確認資料已寫入。

## 5. 安全提醒

「誰可以存取：任何人」代表任何取得 `/exec` 網址的人，都可能讀取、新增、編輯或作廢資料。這個第一版沒有登入、secret token 或細緻權限；請將 `/exec` 網址視為私密能力連結，不要公開貼在社群、截圖或公開 repository。若資料需要多人權限、登入或更高安全性，後續應改用具備驗證的伺服器資料層。

前端只會把你貼入的網址保存到目前瀏覽器的 localStorage，不會把試算表 ID 或網址寫入此專案原始碼。
